## Notes

- Sessions come from the fixture as an explicit `Cookie` header, so no step writes.
- Every request carries `Host: plane-fixture.test`: Django's `cache_page` key
  hashes `request.build_absolute_uri()`, the S3 presigner signs
  `request.get_host()` (`plane/settings/storage.py:54`), and the `/api/v1/` log
  message records the Host header. Without a fixed Host those values differ
  between two targets purely because their ports differ.
- The scenarios use Redis DBs 6 and 7. The harness default `[1, 2]` is shared
  by every agent on the dev stack, and a concurrent run that writes a
  `cache_page` key between our A and B steps turns into a Redis DIFF that
  exists only because two runs share an index.
- `PYTHONHASHSEED=0` is set for both targets: some views iterate a Python
  `set` when building their response (`ProjectSummaryAPIEndpoint`), so JSON key
  order otherwise follows the process's hash seed.
- Cyclic windows are relative to the fixture build time; no scenario depends
  on the exact day a cycle is read.
